🎯 KEY IMPROVEMENTS:
═══════════════════════════════════════════════════════════════════════════

BEFORE (Pseudo-streaming):
  ┌─────────────────────────────────────────────────┐
  │ Request → Wait for ALL → Return complete bytes  │
  └─────────────────────────────────────────────────┘
  
AFTER (True streaming):
  ┌─────────────────────────────────────────────────────────┐
  │ Request → Yield chunk 1 → Yield chunk 2 → ... → Done   │
  └─────────────────────────────────────────────────────────┘

🔧 CONFIGURATION:
═══════════════════════════════════════════════════════════════════════════

In .env:
  ENABLE_STREAMING_TTS=true   ← Enables streaming

When ENABLED:
  • Endpoint: .../freya-tts/stream
  • Method: synthesize_speech_streaming_async()
  • Returns: Async generator (yields chunks)
  • Player: play_streaming_async()

When DISABLED:
  • Endpoint: .../freya-tts/audio/speech
  • Method: synthesize_speech_async()
  • Returns: Complete bytes
  • Player: play_bytes()
